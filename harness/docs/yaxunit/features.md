# Возможности YAxUnit (выдержка)

Source: https://github.com/bia-technologies/yaxunit/blob/develop/documentation/docs/features/features.md  
Site: https://bia-technologies.github.io/yaxunit/docs/features/

Точка входа API — модуль `ЮТест`:

- `ЮТест.ОжидаетЧто()` — утверждения
- `ЮТест.Данные()` — тестовые данные (`КонструкторОбъекта`, `СоздатьЭлемент`, `СоздатьДокумент`)
- `ЮТест.ОжидаетЧтоТаблицаБазы()` — проверки ИБ
- `ЮТест.Контекст()` — контекст теста
- `ЮТест.Предикат()` — предикаты
- `ЮТест.Варианты()` — варианты параметров
- `ЮТест.Упал` / `ЮТест.Пропустить`

Регистрация — обязательный `ИсполняемыеСценарии` + `ЮТТесты.Добавить...`.

Тестовые данные: создавать программно через `ЮТест.Данные()`, не руками в ИБ.

HTTP: `ЮТест.Данные().HTTPСервисЗапрос()` — эмуляция входящего HTTP без веб-сервера (для задач вроде фильтра склада).
