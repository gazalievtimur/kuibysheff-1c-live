# Пишем первый тест

Source: https://bia-technologies.github.io/yaxunit/docs/getting-started/first-test/  
License: public YAxUnit docs (BIA Technologies). Snapshot for 1c-live eval.

Тесты YAxUnit пишутся в **расширении** (новое, не заимствованный общий модуль).

Обязательна экспортная процедура `ИсполняемыеСценарии` — в 1С нет рефлексии, движок узнаёт тесты только из регистрации.

```bsl
Процедура ИсполняемыеСценарии() Экспорт
    
    ЮТТесты.ДобавитьТест("Сложение");

КонецПроцедуры

Процедура Сложение() Экспорт

    РезультатСложения = 2 + 2;
    ЮТест.ОжидаетЧто(РезультатСложения)
        .Равно(4);

КонецПроцедуры
```

- Регистрация: модуль `ЮТТесты`, метод `ДобавитьТест("ИмяЭкспортнойПроцедуры")`.
- Утверждения: `ЮТест.ОжидаетЧто(Значение).Равно(...)`.
- Параметры: `.СПараметрами(...)` при регистрации; сигнатура теста принимает те же аргументы.
- Цепочки: `.Заполнено().ИмеетТип("Число, Строка").Равно(Результат)`.

Полное руководство: https://bia-technologies.github.io/yaxunit/docs/features/
Примеры движка: https://github.com/bia-technologies/yaxunit/tree/develop/tests/src/CommonModules
