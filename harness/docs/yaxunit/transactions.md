# Транзакции и очистка данных

Source: https://github.com/bia-technologies/yaxunit/blob/develop/documentation/docs/features/test-registration.md  
API: `ЮТТесты.ВТранзакции`, `ЮТТесты.УдалениеТестовыхДанных`

```bsl
Процедура ИсполняемыеСценарии() Экспорт
    ЮТТесты
        .ВТранзакции()
        .УдалениеТестовыхДанных()
        .ДобавитьТестовыйНабор("РасходТовара")
            .ДобавитьСерверныйТест("Тест_КоличествоНоль_НеЗаписывается");
КонецПроцедуры
```

- `ВТранзакции()` — выполнение теста в транзакции (откат побочных эффектов записи/проведения).
- `УдалениеТестовыхДанных()` — удаляет объекты, созданные через `ЮТест.Данные()`, даже вне транзакции.

Для документов (запись / проведение) на сервере предпочитать `.ДобавитьСерверныйТест` + `.ВТранзакции()`.
