# Регистрация тестовых методов

Source: https://github.com/bia-technologies/yaxunit/blob/develop/documentation/docs/features/test-registration.md  
Site: https://bia-technologies.github.io/yaxunit/

В каждом тестовом модуле — экспортная `ИсполняемыеСценарии`. В ней **только регистрация**, без создания данных ИБ.

```bsl
Процедура ИсполняемыеСценарии() Экспорт
    ЮТТесты
        .ДобавитьТестовыйНабор("Документы")
            .ДобавитьТест("Тест_КоличествоНоль_НеЗаписывается")
            .ДобавитьСерверныйТест("Тест_ОтрицательныеОстатки_НеПроводится");
КонецПроцедуры
```

API `ЮТТесты`:

- `ДобавитьТест(ИмяМетода, Представление = "", Теги = "", Контексты = Неопределено)`
- `ДобавитьСерверныйТест` / `ДобавитьКлиентскийТест`
- `ДобавитьТестовыйНабор(Имя)`
- `СПараметрами(...)` — повторные вызовы теста с разными аргументами
- `ВТранзакции()` — тест в транзакции
- `УдалениеТестовыхДанных()` — удалить данные, созданные через `ЮТест.Данные()`
- `Перед("Подготовка")` / `После("Очистка")`

Имя экспортной процедуры должно совпадать с именем, переданным в `ДобавитьТест`.
