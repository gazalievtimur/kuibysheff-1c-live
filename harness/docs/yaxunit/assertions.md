# Утверждения

Source: https://bia-technologies.github.io/yaxunit/docs/features/assertions/  
API: https://bia-technologies.github.io/yaxunit/api/ЮТУтверждения

Ожидания формулируются через `ЮТест.ОжидаетЧто(...)`, а не через ручной `ВызватьИсключение`.

```bsl
ЮТест.ОжидаетЧто(ДанныеЗаписи)
    .Свойство("Поставщик").Равно(ДанныеОбъекта.Поставщик)
    .Свойство("Товары")
        .ИмеетДлину(1)
        .Свойство("Товары[0].НомерСтроки").Равно(2);
```

Базовые цепочки (из публичного API):

- `.Равно(Ожидание)`
- `.Заполнено()` / `.НеЗаполнено()`
- `.ИмеетТип("Число")`
- `.ИмеетДлину(N)`
- `.Свойство("Имя")`
- проверка методов объекта на выброс исключения (см. API `ЮТУтверждения`)

Данные ИБ: `ЮТест.ОжидаетЧтоТаблицаБазы(...)` (утверждения ИБ).

Рекомендации docs: проверять только то, что нужно сценарию; указывать описания проверок; не писать проверки ради проверок.
