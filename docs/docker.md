# Docker

Один образ `linux/amd64` содержит оркестратор, `kbshff`, code-index, 1c-sntx-sem, BSL Language Server, SearXNG, mcp-searxng и 1c-conf-doc. Портал на порту 8080 задаёт провайдера LLM, внешние эмбеддинги, конфигурацию 1С и свободный текст задачи.

Локальные модели эмбеддингов в образ не входят. Индексация conf-doc и sntx-sem ходит во внешний OpenAI-compatible API и оплачивается по токенам.

## Сборка и запуск

```bash
# Токен нужен только на время сборки: GitHub API иначе отвечает 403.
# Токен не попадает в слои образа (BuildKit secret).
export GITHUB_TOKEN="$(gh auth token)"
docker compose build
WEB_PASSWORD='choose-one' docker compose up -d
```

Без `WEB_PASSWORD` Caddy не спрашивает пароль и пишет об этом в лог.

| Порт | Что открывается |
| --- | --- |
| 8080 | Портал: настройки, конфигурации, задача, прогоны |
| 8050 | Веб-интерфейс 1c-conf-doc |
| 8051 | Веб-интерфейс 1c-sntx-sem (`/admin`) |
| 8888 | SearXNG |

Все четыре порта закрыты одной Basic Auth (`WEB_USER`, по умолчанию `admin`). MCP внутри контейнера ходит на `127.0.0.1` и авторизацию Caddy не проходит.

Если 8080, 8050, 8051 или 8888 уже заняты на хосте, поменяйте левую часть проброса в `docker-compose.yml` (`18080:8080` и так далее). Внутри контейнера порты не меняются.

Данные лежат в томе `/data`: настройки, загруженные выгрузки, прогоны, индексы code-index / conf-doc / sntx-sem, конфиг SearXNG.

## Как провести задачу

1. Откройте **Настройки**. Укажите `base_url`, ключ и модель каждой стадии. Отдельно укажите эмбеддинги (по умолчанию тот же адрес и ключ, модель `text-embedding-3-small`) и нажмите «Проверить».
2. На **Конфигурациях** оставьте учебный «Склад» или загрузите zip XML-выгрузки. Портал сам регистрирует каталог в code-index и индексирует его в conf-doc. Пока ключ эмбеддингов пуст, индексируются только метаданные.
3. **Задача**: выберите конфигурацию, напишите бриф. «Веб-поиск» включает SearXNG на стадиях analyst и yaxunit. Одновременно идёт один прогон.
4. **Прогоны**: `report.json`, файлы `out/` стадий, архивы `out/cfe` и `out/cfe-tests`.

Смена модели эмбеддингов делает старые индексы несовместимыми. Для conf-doc нажмите «Переиндексировать». Для sntx-sem откройте `/admin` и выполните Rebuild Index.

## Платформа 1С

Платформа лицензионная и в образ не кладётся. Смонтируйте каталог установки в `/opt/1cv8` (строка в `docker-compose.yml`) и перезапустите контейнер. Ingest справки:

```bash
docker exec -it <container> sntx-sem ingest --platform-path /opt/1cv8/<версия>/bin
```

Без индекса семантический поиск справки на live-прогоне пустой. Флаг «Прогон YAxUnit на платформе» в форме задачи включается, только если внутри виден `ibcmd`.

## Ограничения

- Образ собирается только под linux/amd64 на Debian 13: готовый `kbshff` требует glibc 2.39+. BSL Language Server запускается на JDK 21 (нужен 17+).
- SearXNG поднимается вместе с контейнером, отдельно его запускать не нужно.
- Индексация большой конфигурации в conf-doc зависит от скорости внешнего API эмбеддингов.
